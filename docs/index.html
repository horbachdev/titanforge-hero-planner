MVP features

Built for real roster planning

Hero Builder

Create heroes with class, Titan Soul promotion, level, seeds, skills, gear, quality, elements, spirits, and Starforge toggles.

Champion Builder

Build champions with rank, Champion Soul, familiar, Aurasong, gear, enchants, and mapped combat aura effects.

Build Library

Save heroes and champions as reusable builds, edit them later, and keep rosters connected to saved build references.

Roster Management

Assemble up to five hero slots plus one champion slot, compare team totals, and inspect element point coverage.

Item Browser

Search imported blueprints, enchantments, skills, affinities, inherent elements, inherent spirits, and Starforge data.

JSON Sharing

Export and import versioned build JSON for backups, testing, and sharing controlled build snapshots.

Workflow

From build idea to roster check

  1. Create and save hero builds.
  2. Create and save champion builds.
  3. Assemble a roster from saved builds.
  4. Review team stats, elements, spirits, and gear effects.
  5. Run a seeded Ress-style quest simulation.
  6. Export builds as JSON when needed.

Combat engine

Ress-style simulation groundwork

Currently modeled

Seeded Monte Carlo runs, enemy crits, AoE rolls, target weighting by threat, barriers, mini-boss modifiers, LCoG slot handling, combat spirits, healing, fatal-blow saves, and mapped champion/Aurasong effects.

Still under validation

Full parity against Ress output rows, every special artifact edge case, Tamas randomness, boosters, rest time, break chance, and non-combat drop side effects.
